# WP Product Catalog Manager

WP Product Catalog Manager is being developed incrementally as a WordPress product catalog plugin.

## Current status

Commit 1 provides only the required file structure and a minimal, secure, inert bootstrap. Product post types, taxonomies, metadata, shortcodes, catalog rendering, filtering, pagination, and front-end behavior are not implemented yet.
