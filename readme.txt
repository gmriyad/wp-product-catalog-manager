A scaffold for an incrementally developed WordPress product catalog plugin.

== Description ==

Version 0.1.0 provides only the plugin structure and a minimal, secure, inert bootstrap. Catalog features will be implemented in later milestones.

== Installation ==

1. Copy the plugin directory to `/wp-content/plugins/`.
2. Activate WP Product Catalog Manager from the WordPress Plugins screen.

The commit-1 scaffold does not register product catalog features.
